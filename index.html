Build: Passing (Go 1.27) Architecture: Clean MVC Zero Reflection at Runtime

High-Performance, Secure Go Microservices.

Struct is a typed-first Go microservice framework featuring Clean Architecture, dual PostgreSQL and MySQL native wire protocols, full authentication (WebAuthn passkeys, RFC 6238 TOTP, HS256 JWT), W3C tracing, Prometheus metrics exposition, and container CPU limit detection.

make compose-up && make check && make run

Hardened Security

Constant-time hash verifications, HS256 algorithm enforcement, 15-minute brute-force lockout, and PII masking in structured logs.

Sub-Millisecond Engine

16-shard FNV mutex rate limiting, sync.Pool buffer reuse, tuned HTTP keep-alive connection pools, and cgroup-aware GOMAXPROCS.

Clean Layering Invariant

Strict decoupling: Platform packages never import Domain packages. Single-method interfaces decouple infrastructure from business logic.

5-Minute Quickstart

Get a production-grade microservice up and running locally in seconds.

1
Start Infrastructure (PostgreSQL & Redis)

Boots PostgreSQL 18 with migrations pre-applied, plus a high-throughput Redis broker.

make compose-up
2
Run Verification Suite (gofmt, go vet, race tests)

Validates the entire codebase under the Go race detector with zero cache.

make check
3
Build & Run API Server

Starts the HTTP API server on port 8080 with live structured logging.

make run

Clean Architecture & Package Layout

Struct organizes code into strictly isolated boundaries. Business models, controllers, and services belong to the domain layer; transport, security, storage, and telemetry belong to the platform layer.

cmd/ ├── api/ # Composition root execution entrypoint (wires dependencies, binds port) └── struct/ # Operational CLI entrypoint (codegen, migrations, doctor, relay) internal/ ├── app/ # Application Composition Root: Build(), Routes(), DI wiring │ └── cli/ # CLI subcommands (make, migrate, doctor, serve, relay, report) ├── mvc/ # Domain & Presentation Layer │ ├── models/ # Domain entities (User, Session, Credentials) │ ├── services/ # Business logic (UserService, AuthService) │ ├── controllers/# HTTP handlers & error renderers │ ├── views/ # Response DTOs │ └── apperr/ # Typed domain error hierarchy ├── platform/ # Pure Infrastructure Layer (Never imports internal/mvc) │ ├── config/ # Strict environment loader (Postgres, MySQL, Broker, Keys) │ ├── http/ # Router, middleware chain, and appctx RequestContext │ ├── store/ # Interchangeable store.Driver: PostgreSQL & MySQL native wire protocols │ ├── security/ # Authn (JWT), TOTP (RFC 6238), WebAuthn passkeys, Authz │ ├── events/ # Domain events, Message Broker factory, and Outbox Relay │ ├── logging/ # Context-aware slog with PII redaction │ ├── metrics/ # Prometheus registry & Go runtime collector │ ├── tracing/ # W3C Traceparent parser & OTLP HTTP span exporter │ └── procs/ # cgroup v1/v2 CPU limit quota reader └── support/ # Cryptography, validation, and in-process job runners

Robust Configuration System

The internal/platform/config package parses all configuration once at startup. It guarantees strict type validation, supports both PostgreSQL and MySQL via environment variables, and fails fast in production if required cryptographic keys are missing.

Variable Default Options / Dialects Description
APP_ENV development development, production, test Enforces production constraints (mandatory keys, disabled pprof).
DB_DRIVER memory postgres, mysql, memory Backing relational store driver. Also accepts DATABASE_DRIVER or DB_TYPE.
DATABASE_URL (empty) postgres://... or mysql://... Direct database connection DSN. If omitted, assembled from DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME.
DATABASE_REPLICA_URL (empty) Connection URL Routes read-heavy queries and reporting aggregations to a database read replica.
MESSAGE_BROKER memory memory, redis, nats, kafka, log Selects asynchronous pub/sub transport for domain events and outbox relay.
JWT_SIGNING_KEY (ephemeral dev) 32+ byte string HMAC-SHA256 secret for access token issuance. Required in production.
ENCRYPTION_KEY (ephemeral dev) AES-256 string Derived to 32 bytes for TOTP secret encryption at rest. Required in production.
OTEL_EXPORTER_OTLP_ENDPOINT (empty) HTTP URL (e.g. http://localhost:4318/v1/traces) Exports completed W3C trace spans via standard OTLP/HTTP JSON protocol.

Request Lifecycle & AppContext

Struct coordinates request state through a typed appctx.RequestContext attached to the standard context.Context. Downstream services and loggers access correlation metadata without manual type assertions. 

func (c *UserController) Get(w http.ResponseWriter, r *http.Request) {
    ctx := r.Context()

    // Access correlation identifiers populated by upstream middleware
    reqID := appctx.RequestID(ctx)       // e.g. "a1b2c3d4e5f6"
    traceID := appctx.TraceID(ctx)       // W3C Traceparent TraceID
    clientIP := appctx.ClientIP(ctx)     // Trusted real client IP
    userID, isAuth := appctx.UserID(ctx) // Authenticated user ID (from Bearer token)

    // Context-aware logging automatically attaches trace_id and request_id
    logger := appctx.Logger(ctx)
    logger.Info("fetching user profile", "target_id", r.PathValue("id"), "actor_id", userID)

    // Business logic...
}

Typed Domain Errors (`apperr`)

Domain logic returns pure Go error values from internal/mvc/apperr. The controller layer maps them directly to RFC 7807 problem details JSON payloads with appropriate HTTP status codes.

Error Constructor HTTP Status Error Code Typical Scenario
apperr.NotFound(entity, id) 404 Not Found NOT_FOUND Requested record does not exist in store.
apperr.Conflict(msg) 409 Conflict CONFLICT Unique constraint violation (e.g. email already registered).
apperr.Validation(fields) 422 Unprocessable VALIDATION_FAILED Request payload violates business validation constraints.
apperr.Unauthorized(msg) 401 Unauthorized UNAUTHORIZED Missing or expired Bearer token; invalid credentials.
apperr.Forbidden(msg) 403 Forbidden FORBIDDEN Policy evaluation denied access to the requested action.
apperr.Internal(msg, err) 500 Internal Error INTERNAL_ERROR Unexpected infrastructure failure (sanitized from client).

Hardened Authentication Stack

Struct features enterprise-grade authentication with password hashing (Argon2id), RFC 6238 TOTP with single-use backup codes, FIDO2/WebAuthn resident passkeys, and HTTP Bearer token validation middleware. 

# 1. Obtain JWT access token via password or passkey login:
curl -X POST http://localhost:8080/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"alice@example.com","password":"secure-password-123"}'

# Response:
# {"access_token":"eyJhbGciOi...","refresh_token":"d8f1e..."}

# 2. Access protected endpoints using the Bearer token:
curl -X GET http://localhost:8080/v1/auth/passkeys \
  -H "Authorization: Bearer eyJhbGciOi..."

# 3. Invalid or expired tokens return 401 Unauthorized immediately:
# {"error":"invalid or expired token"}
// 1. Begin Passkey Registration
POST /v1/auth/passkeys/register/begin (Requires Bearer token)
Response contains WebAuthn PublicKeyCredentialCreationOptions

// 2. Browser calls navigator.credentials.create()
// 3. Finish Passkey Registration
POST /v1/auth/passkeys/register/finish
Attaches newly minted WebAuthn credential public key (COSE key format)

// 4. Fully Passwordless (Discoverable Credential) Login:
POST /v1/auth/passkeys/login/begin
Request: {} (empty body signals resident key autofill)
Response: PublicKeyCredentialRequestOptions (allowCredentials: [])
// 1. Enroll TOTP
POST /v1/auth/totp/enroll (Requires Bearer token)
Response: {"secret":"JBSWY3DPEHPK3PXP","otpauth_uri":"otpauth://totp/..."}

// 2. Confirm TOTP with a valid 6-digit code
POST /v1/auth/totp/confirm
Request: {"code":"123456"}
Response: {"backup_codes":["a1b2c3d4","e5f6g7h8",...]}
Note: Backup codes are hashed with SHA-256 at rest; this is the only time they are displayed plaintext.

Interactive HTTP API Reference

Every route adheres to uniform RFC 7807 error structures. Routes marked with ✱ require an Authorization: Bearer <token> header.

Method Path Auth Description
GET /healthz Public Service liveness probe reporting uptime, application name, and version
GET /readyz Public Service readiness probe checking database and broker connectivity
GET /metrics Public Prometheus text exposition format (HTTP latencies, errors, runtime)
POST /v1/users Public Registers a new user; validates input and hashes password with Argon2id
GET /v1/users/{id} Public Fetches user profile by identifier; emits 404 on missing record
POST /v1/auth/login Public Authenticates email + password; returns JWT access and refresh tokens
POST /v1/auth/refresh Public Exchanges valid refresh token for a fresh access token
POST /v1/auth/logout Public Revokes single refresh token session
POST /v1/auth/logout-all ✱ Bearer Revokes all active sessions and refresh tokens for the authenticated user
POST /v1/auth/mfa/totp Public Redeems login MFA ticket using TOTP authenticator code or single-use backup code
POST /v1/auth/totp/enroll ✱ Bearer Generates unconfirmed TOTP secret key and otpauth:// URI
POST /v1/auth/totp/confirm ✱ Bearer Confirms enrollment with code; returns plaintext backup codes
DELETE /v1/auth/totp ✱ Bearer Disables TOTP multi-factor authentication and purges backup codes
GET /v1/auth/totp/backup-codes ✱ Bearer Returns count of unredeemed backup codes remaining
POST /v1/auth/passkeys/register/begin ✱ Bearer Begins WebAuthn credential registration; returns creation options
POST /v1/auth/passkeys/register/finish ✱ Bearer Validates authenticator attestation response; persists public key
GET /v1/auth/passkeys ✱ Bearer Lists registered WebAuthn passkeys for the caller
PATCH /v1/auth/passkeys/{id} ✱ Bearer Renames an existing passkey label
DELETE /v1/auth/passkeys/{id} ✱ Bearer Revokes and deletes a passkey credential
POST /v1/auth/passkeys/login/begin Public Begins WebAuthn assertion ceremony (supports resident discoverable login)
POST /v1/auth/passkeys/login/finish Public Verifies WebAuthn assertion signature; issues JWT tokens

CLI Operational Tooling (`struct`)

The struct CLI automates code generation, dual migrations, outbox relays, and development diagnostics. 

# Scaffolding individual clean architecture components:
struct make model Invoice                                          # internal/mvc/models/invoice.go
struct make controller Invoice                                     # internal/mvc/controllers/invoice_controller.go
struct make service Invoice                                        # internal/mvc/services/invoice_service.go
struct make repository Invoice                                     # Scaffolds both Postgres & MySQL repositories
struct make dto Invoice                                            # internal/mvc/views/invoice_view.go
struct make enum PaymentStatus --values=pending,completed,failed   # internal/mvc/models/payment_status_enum.go
struct make policy Invoice                                         # internal/platform/security/authz/invoice_policy.go
struct make event InvoicePaidV1                                    # internal/platform/events/invoice_paid_v1.go
struct make job SendInvoiceEmail                                   # internal/support/queue/send_invoice_email_job.go
struct make locale de                                              # internal/platform/i18n/locales/de.json
struct make rpc BillingService                                     # internal/platform/rpc/billing_service.go

# Scaffold the ENTIRE stack in one single command:
struct make resource Invoice                                       # Model + DTO + Service + Repositories + Controller
# Create timestamped up/down SQL files for Postgres and MySQL:
struct migrate create create_invoices_table

# Apply all pending migrations against DATABASE_URL:
struct migrate up

# Rollback the last applied migration:
struct migrate down

# Inspect applied vs pending migrations:
struct migrate status
# Diagnostics, inspection, and operations:
struct serve          # Boots HTTP API server
struct routes         # Displays full declarative route table (offline, no socket bound)
struct health         # Probes local /readyz endpoint
struct version        # Displays commit, version, and compiler metadata
struct doctor         # Verifies environment, DB connectivity, and i18n completeness
struct relay          # Runs standalone transactional outbox polling daemon
struct report signups # Runs aggregate SQL report over the last 30 days

Production Docker Deployment

Struct packages into a secure, minimal distroless container running as a non-root user with container cgroup v2 GOMAXPROCS auto-detection. 

# Multi-stage distroless build:
# Stage 1: Build binary with trimpath and build tags
FROM golang:1.24-bookworm AS builder
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o /out/struct-api ./cmd/api

# Stage 2: Distroless runtime (non-root, minimal attack surface)
FROM gcr.io/distroless/static-debian12:nonroot AS runtime
WORKDIR /app
COPY --from=builder /out/struct-api /app/struct-api
EXPOSE 8080
USER nonroot:nonroot
ENTRYPOINT ["/app/struct-api"]
services:
  api:
    build:
      context: ..
      dockerfile: docker/Dockerfile
    ports:
      - "8080:8080"
    environment:
      - APP_ENV=production
      - DB_DRIVER=postgres
      - DATABASE_URL=postgres://postgres:secret@postgres:5432/struct_prod?sslmode=disable
      - MESSAGE_BROKER=redis
      - BROKER_URL=redis://redis:6379
      - JWT_SIGNING_KEY=production-jwt-secret-key-must-be-32-chars-long
      - ENCRYPTION_KEY=production-aes256-secret-key-must-be-32-bytes
    depends_on:
      - postgres
      - redis

  postgres:
    image: postgres:18-alpine
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: secret
      POSTGRES_DB: struct_prod
    ports:
      - "5432:5432"

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

struct migrate up

# Step 5: Rollback if needed:
struct migrate down

func ProtectWithBearer(verifier authn.TokenVerifier, next http.Handler) http.Handler {
    return middleware.RequireAuth(verifier)(next)
}

// 2. Accessing authenticated UserID inside any handler:
func (c *InvoiceController) Create(w http.ResponseWriter, r *http.Request) {

        // middleware.RequireAuth already blocks unauthenticated requests,
        // but UserIDFrom / appctx.UserID provides safe typed access:
        writeError(w, http.StatusUnauthorized, "unauthorized", nil)
        return

}

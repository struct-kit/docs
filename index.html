Build: Passing (Go 1.27) Architecture: Clean MVC Zero Reflection at Runtime

High-Performance, Secure Go Microservices.

Struct is a typed-first Go microservice framework featuring Clean Architecture, dual PostgreSQL and MySQL wire protocols, full authentication (WebAuthn passkeys, RFC 6238 TOTP, HS256 JWT), W3C tracing, Prometheus text exposition, and container CPU limit detection.

make compose-up && make check && make run

Hardened Security

Constant-time hash verifications, HS256 algorithm enforcement, 15-minute brute-force lockout, and PII masking in structured logs.

Sub-Millisecond Engine

16-shard FNV mutex rate limiting, sync.Pool buffer reuse, tuned HTTP keep-alive connection pools, and cgroup-aware GOMAXPROCS.

Clean Layering Invariant

Strict decoupling: Platform packages never import Domain packages. Single-method interfaces decouple infrastructure from business logic.

Clean Architecture & Package Layout

Struct organizes code into strictly isolated boundaries. Business models, controllers, and services belong to the domain layer; transport, security, storage, and telemetry belong to the platform layer.

cmd/ ├── api/ # Composition root execution entrypoint (wires dependencies, binds port) └── struct/ # Operational CLI entrypoint (codegen, migrations, doctor, relay) internal/ ├── app/ # Application Composition Root: Build(), Routes(), DI wiring ├── mvc/ # Domain & Presentation Layer │ ├── models/ # Domain entities (User, Session, Credentials) │ ├── services/ # Business logic (UserService, AuthService) │ ├── controllers/# HTTP handlers & error renderers │ ├── views/ # Response DTOs │ └── apperr/ # Typed domain error hierarchy ├── platform/ # Pure Infrastructure Layer (Never imports internal/mvc) │ ├── config/ # Strict environment loader (AppName, DBDriver, Broker) │ ├── http/ # Router, middleware chain, and appctx RequestContext │ ├── store/ # Interchangeable store.Driver: PostgreSQL & MySQL │ ├── security/ # Authn (JWT), TOTP (RFC 6238), WebAuthn passkeys, Authz │ ├── events/ # Domain events, Message Broker factory, and Outbox Relay │ ├── logging/ # Context-aware slog with PII redaction │ ├── metrics/ # Prometheus registry & Go runtime collector │ ├── tracing/ # W3C Traceparent parser & span exporter │ └── procs/ # cgroup v1/v2 CPU limit quota reader └── support/ # Cryptography, validation, and in-process job runners

Request Lifecycle & AppContext

Struct coordinates request state through a typed appctx.RequestContext attached to the standard context.Context. Downstream services and loggers access correlation metadata without manual type assertions. 

func (c *UserController) Get(w http.ResponseWriter, r *http.Request) {
    ctx := r.Context()

    // Access AppContext metadata directly
    reqID := appctx.RequestID(ctx)       // e.g. "a1b2c3d4e5f6"
    traceID := appctx.TraceID(ctx)       // W3C Trace Context
    clientIP := appctx.ClientIP(ctx)     // Trusted client IP
    locale := appctx.Locale(ctx)         // Resolved locale ("en", "es")

    // Verify authenticated user
    userID, ok := appctx.UserID(ctx)
    if !ok {
        writeError(w, http.StatusUnauthorized, "authentication required", nil)
        return
    }

    // Logger automatically injects request_id, trace_id, and user_id
    c.logger.InfoContext(ctx, "retrieving user record", "target_id", r.PathValue("id"))
}

Diagnostics, Health Checks & Profiling

Struct exposes standard endpoints for cluster management, load balancing, and runtime diagnostics.

Method Endpoint Purpose Response
GET /healthz Process liveness probe; reports uptime and application version. {"status":"ok","app":"...","version":"..."}
GET /readyz Multi-component readiness; pings database and broker with timeout. {"status":"ready","checks":{"database":"healthy"}}
GET /metrics Prometheus text format; HTTP duration histograms, request totals, Go runtime. text/plain; version=0.0.4
GET /debug/pprof/* Runtime profiling (index, profile, trace, goroutines, heap allocations). HTML / Binary Profiles (Configurable)

Interactive HTTP API Reference

Every route adheres to uniform RFC 7807 error structures. Routes marked with ✱ require an Authorization: Bearer <token> header.

Method Path Auth Description
POST /v1/users Public Creates a new user account with email, password, and locale.
GET /v1/users/{id} Public Fetches user profile by identifier.
POST /v1/auth/login Public Authenticates email + password; returns token pair or MFA challenge ticket.
POST /v1/auth/refresh Public Rotates refresh token for a fresh token pair.
POST /v1/auth/logout Public Revokes single session identified by refresh token.
POST /v1/auth/logout-all ✱ Bearer Revokes all active sessions for caller across all devices.
POST /v1/auth/totp/enroll ✱ Bearer Generates new RFC 6238 TOTP enrollment secret and QR uri.
POST /v1/auth/totp/confirm ✱ Bearer Confirms enrollment code and generates single-use backup recovery codes.
DELETE /v1/auth/totp ✱ Bearer Disables TOTP 2FA and deletes remaining backup codes.
POST /v1/auth/passkeys/register/begin ✱ Bearer Initiates WebAuthn passkey registration ceremony.
POST /v1/auth/passkeys/register/finish ✱ Bearer Completes ceremony, validates COSE public key, and persists passkey.
POST /v1/auth/passkeys/login/begin Public Starts passwordless WebAuthn login (email-first).
POST /v1/auth/passkeys/login/finish Public Verifies authenticator assertion and issues session tokens.

CLI Operational Tooling (`struct`)

The struct CLI automates code generation, migrations, outbox relays, and development diagnostics. 

# Scaffolding clean architecture components:
struct make model Invoice                                          # internal/mvc/models/invoice.go
struct make controller Invoice                                     # internal/mvc/controllers/invoice_controller.go
struct make service Invoice                                        # internal/mvc/services/invoice_service.go
struct make dto Invoice                                            # internal/mvc/views/invoice_dto.go
struct make enum PaymentStatus --values=pending,completed,failed   # internal/mvc/models/payment_status.go
struct make policy Invoice                                         # internal/platform/security/authz/invoice_policy.go
struct make repository Invoice                                     # Dual-dialect: Postgres & MySQL repositories
struct make event InvoicePaidV1                                    # internal/platform/events/invoice_paid_v1.go
struct make job SendInvoiceEmail                                   # internal/support/queue/send_invoice_email_job.go
struct make locale de                                              # internal/platform/i18n/locales/de.json
struct make rpc BillingService                                     # internal/platform/rpc/billing_service.go
# Create timestamped up/down SQL files for Postgres and MySQL:
struct migrate create create_invoices_table

# Apply all pending migrations against DATABASE_URL:
struct migrate up

# Rollback the last applied migration batch:
struct migrate down
# Diagnostics, inspection, and operations:
struct serve          # Boots HTTP API server
struct routes         # Displays full declarative route table (offline, no socket bound)
struct health         # Probes local /readyz endpoint
struct version        # Displays commit, version, and compiler metadata
struct doctor         # Verifies environment, DB connectivity, and i18n completeness
struct relay          # Runs standalone transactional outbox polling daemon
struct report signups # Runs aggregate SQL report over the last 30 days
